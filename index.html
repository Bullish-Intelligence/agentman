agentman

A CLI for talking to typed agents. Every model call and tool call is recorded, always.

The project has a durable, workspace-scoped agent runtime with:

  • typed agent specifications and client-side output validation;
  • a Unix-socket client/daemon split with SSE streaming;
  • Postgres-backed threads, runs, model events, snapshots, messages, and tool effects;
  • workspace-scoped coder tools with file-image evidence for recovery;
  • status inspection and policy-gated DBOS workflow resumption; and
  • concurrent stdin fan-out through pipe --each.

The detailed documentation set is the source for the product and operational picture:

  • Documentation index — reading paths and document map.
  • Overview — what exists, what it means, and the current status boundaries.
  • Getting started — development setup and first typed turn.
  • Architecture — request flow, ownership, durability, streaming, and concurrency.
  • Persistence and recovery — schemas, snapshots, effects, crash behavior, and resume.
  • CLI and configuration reference — commands, config, agent specs, exit codes, and the socket API.
  • Development guide — repository layout, invariants, verification, and contribution workflow.
  • Roadmap and gaps — what the system should have next and what is not yet operationally complete.
  • ADR 0001 — proposed activity record across Pi, Claude Code, and Codex, with Atuin owning commands.

Run everything inside devenv shell. See AGENTS.md for the working agreement.

Getting started

devenv shell          # enter the pinned environment
uv sync --all-extras  # app dependencies and the dev tools
devenv up -d          # start the project Postgres service

See Getting started for daemon configuration and a first typed turn.

Verify

Run the checks from the repository root:

devenv shell -- ruff check src tests
devenv shell -- ruff format --check src tests
devenv shell -- ty check src
devenv shell -- pytest

The devenv.nix tasks expose the same checks. The default pytest run is hermetic. Integration tests need AGENTMAN_RUN_INTEGRATION=1 and an explicit AGENTMAN_TEST_DATABASE_URL. Keep devenv.lock and uv.lock in Git.

Version control

Use Git. Keep a change focused. Keep devenv.lock and uv.lock in the same change as the inputs they pin. Run the checks before you push. Open a pull request for review.

Layout

src/agentman/             # package source
src/structured_agents/    # provider-neutral agent specification
tests/                    # pytest tests
docs/                     # product, architecture, and operations documentation
devenv.nix                # shell, services, and check tasks
devenv.yaml               # inputs
pyproject.toml            # project metadata and tool configuration
